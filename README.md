# analog-overdrive-tube-screamer-modified
Analog overdrive pedal based on the Tube Screamer topology, including circuit analysis, PCB assembly, modification, testing, and electrical characterization.

## Analog Electronics Analysis, Assembly, Modification, and Testing

This project documents the construction and analysis of an analog guitar overdrive pedal based on the Tube Screamer circuit topology by Ibanez.

The pedal uses an op-amp, diode soft and hard clipping network, analog filtering stages, transistor buffering, and a 9 V single-supply power system to modify the amplitude and frequency characteristics of an electric guitar signal, while keeping the system usable with existing pedalboard iterations.

The project includes circuit analysis, component-level documentation, PCB assembly, soldering, off-board wiring, electrical testing, troubleshooting, and implementation of a switchable frequency-response modification.

## Project Objectives
- Make a meaningful modification to an existing and popular pedal to fix a common problem with the unit.
- Understand the signal path of a Tube Screamer-style analog overdrive circuit.
- Analyze the purpose of each major circuit subsystem.
- Understand operational-amplifier gain and feedback.
- Analyze diode clipping and nonlinear distortion.
- Understand RC high-pass and low-pass filtering.
- Analyze the pedal's characteristic mid-frequency response.
- Understand transistor input and output buffering.
- Understand operation from a single 9 V power supply.
- Study the use of a virtual ground/reference voltage in single-supply audio circuits.
- Assemble and solder a through-hole PCB.
- Implement off-board wiring for potentiometers, audio jacks, switches, and power.
- Add and document a switchable "fat" modification.
- Measure important DC voltages using a digital multimeter.
- Verify continuity and identify unintended shorts.
- Compare expected circuit behavior with measured behavior.
- Document troubleshooting and design decisions.
